# インストールとデモ取引

**Windows PowerShell、Python 3.11または3.12、Git**を使う手順です。口座画面を開いたあと、仮想資金で売買を1回実行します。

[READMEに戻る](../../README.ja.md)

## インストール

PowerShellを開き、次のコマンドを実行します。

```powershell
git clone https://github.com/easygap/quant_trader.git
cd quant_trader
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

設定ファイルを作成します。すでにファイルがある場合は上書きしません。

```powershell
if (-not (Test-Path config/settings.yaml)) {
    Copy-Item config/settings.yaml.example config/settings.yaml
}
if (-not (Test-Path .env)) {
    Copy-Item .env.example .env
}
```

`config/settings.yaml`を開き、`trading`の下にある`mode`が`paper`になっていることを確認してください。設定例の初期値は`paper`です。デモ取引はNungum内で仮想資金を使って処理します。証券会社が提供するデモ取引サービスとは別のものです。

KIS APIに接続する場合は、APIキーなどの認証情報と口座番号を`.env`に入力します。このファイルはGitに登録しないでください。実際の資金で売買する場合は、[実口座の設定ガイド（韓国語）](../PAPER_TO_LIVE_RUNBOOK.md)に従って別途設定が必要です。

## 口座画面を開く

```powershell
.\.venv\Scripts\python.exe main.py --mode dashboard
```

このPowerShellウィンドウを開いたまま、同じPCのブラウザで[http://127.0.0.1:8080](http://127.0.0.1:8080)にアクセスします。このコマンドで起動するのは口座画面です。自動売買は別途実行します。

インストール直後は取引履歴がありません。READMEの画像は既存のデモ口座を撮影したもので、同じ残高やリターンが最初から表示されるわけではありません。

ポート8080が使用中の場合は、別のポートを指定できます。

```powershell
.\.venv\Scripts\python.exe main.py --mode dashboard --dashboard-port 8081
```

この場合の接続先は[http://127.0.0.1:8081](http://127.0.0.1:8081)です。

## デモ取引

口座画面を起動したまま、別のPowerShellウィンドウを開き、インストール先の`quant_trader`フォルダに移動します。

[config/baskets.yaml](../../config/baskets.yaml)には、次の2種類の設定があります。

| 設定ID                | 画面の表示名     | 初期設定                                                                                                                                                |
| --------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `kr_pocket`           | ETF 적립         | KODEX 200（`069500`）とTIGERのCD金利連動ETF（`357870`）。初期資金30万ウォン、毎月の積立予定額10万ウォン。追加入金は手動で記録します。デモ取引専用です。 |
| `kr_diversified_hold` | 대형주 분산 투자 | 韓国大型株60%・現金40%を目標に配分します。                                                                                                              |

銘柄と配分比率は、このファイルで変更できます。1株単位の売買や最低発注金額の制約により、目標どおりの比率にならない場合があります。

まず、発注予定の内容を確認します。株価を取得するためインターネット接続が必要ですが、このコマンドでは注文しません。

```powershell
.\.venv\Scripts\python.exe main.py --mode rebalance --basket kr_pocket --dry-run
```

銘柄と数量を確認し、**`trading.mode`が`paper`のままであることを確認してから**、次を実行します。

```powershell
.\.venv\Scripts\python.exe main.py --mode rebalance --basket kr_pocket
```

これで1回分の売買処理が実行されます。終了後、口座画面を再読み込みしてください。株価を取得できない場合や注文条件を満たさない場合は、売買しないことがあります。理由はPowerShellの出力で確認できます。

定期的に実行する場合は、[自動実行の設定（韓国語）](../PROJECT_GUIDE.md)を参照してください。自動売買を続ける間は、PCと売買プログラムを起動しておく必要があります。

## 画面の使い方

画面は現在、韓国語のみです。金額は韓国ウォン（KRW）、日時は韓国標準時（UTC+9）で表示します。PCのタイムゾーンを変更しても、取引日や月別リターンの集計日は変わりません。

| 画面の表示                          | 意味・操作                                                                                       |
| ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| **ETF 적립** / **대형주 분산 투자** | ETF口座と株式口座を切り替えます。                                                                |
| **투자원금**                        | 初期資金と追加入金を合わせた投資元本。                                                           |
| **평가금액**                        | 現金を含む口座全体の評価額。                                                                     |
| **수익률**                          | 入出金の影響を除いた時間加重収益率。                                                             |
| **입체** / **평면**                 | 同じリターンを立体・平面で表示します。立体チャートの帯の幅は、別の指標を表すものではありません。 |
| **최근 날짜**                       | 日付のスライダーを動かしたあと、最新の記録に戻ります。                                           |
| **낙폭과 일별 기록 자세히 보기**    | ピークからの下落率と日別データを開きます。                                                       |
| **이전 기록** / **다음 기록**       | 日別データを前後のページに切り替えます。1ページ最大100件です。                                   |
| **기록 내려받기**                   | 選択した期間の全件をCSVで保存します。表示中のページだけではありません。                          |
| **자동매매 상태**                   | 前回の実行時刻、取引停止の有無、証券会社との接続やデータの更新状況を確認します。                 |
| **다시 확인**                       | 稼働状況を再取得します。                                                                         |

![日別データとピークからの下落率を表示した韓国語の画面](../images/history-table-20260922.png)

保有銘柄の表にある比率は取得金額ベースです。時価による評価額と評価損益は表の下に表示します。

### 仮想資金を追加する

**적립금 기록**を押し、口座と金額を入力します。**내용 확인**を押して、口座・金額・デモ取引であることを確認してから登録してください。デモ口座の元本に加算されます。銀行口座からの振替や自動引き落としを行う機能ではありません。

## バックテスト

公開している売買ルールの比較を実行します。

```powershell
.\.venv\Scripts\python.exe tools/risk_review.py --as-of 2026-09-22
```

結果は`reports/research/risk_review_20260922.json`、グラフは`docs/images/risk-review-20260922.png`に保存します。指定日を変えるとファイル名も変わります。このコマンドから注文が出ることはありません。

比較に使うデータの最終日が異なる場合は、すべてそろう日までで計算します。9月22日の検証では指数データが9月17日までだったため、比較も9月17日までです。取引コストなどの前提条件は[検証結果（韓国語）](../RISK_REVIEW_20260922.md)を参照してください。

デモ取引やバックテストの成績は、実際の利益を保証するものではありません。CD金利連動ETFも元本保証ではありません。

## 別の端末からのアクセス

画面はスマートフォンの幅にも対応していますが、`127.0.0.1`は起動したPCからしか開けません。別の端末から利用するには、接続先と認証を別途設定する必要があります。[設定ガイド（韓国語）](../PROJECT_GUIDE.md)を参照してください。
